## One-paragraph description

Para! is an offline-first commute copilot for Filipino commuters. You ask in Taglish where you want to go, and Tsupher, the jeepney mascot, answers with route options, step-by-step boarding and alighting points, and a fare breakdown with an "as of" date. You can refine with follow-ups ("may mas mura?") and declare what-ifs ("iwas EDSA"), which are always labeled as simulations. It is a web app that keeps working in airplane mode after one visit: the route data, the route planner and the language model all run on the device, and nothing the rider types is sent anywhere. Routes and fares are never generated by AI. A deterministic graph search computes them from a route pack; the on-device model only helps read unclear questions, and its output is checked against the pack before use. The current build runs on a clearly labeled synthetic test network; a ride-verified corridor is the next step.

## Why local AI

- **It works where commuters actually lose signal.** Understanding the question and planning the route happen on the phone, so there is no server to reach from a tunnel, a terminal or a provincial road.
- **Privacy by construction.** Where you are going is sensitive. With on-device inference there is no request to log: the app's own panel and the browser's network tab both show zero requests to other servers.
- **AI where it helps, rules where it matters.** A small local model is enough to read Taglish into a structured request. It is never trusted for facts: routes, fares and times come from a deterministic planner, and model output that names a place outside the route pack is discarded.
